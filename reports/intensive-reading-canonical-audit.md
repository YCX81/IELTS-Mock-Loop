## Selection policy

1. Prefer a completed intensive-reading document outside recovered-sources.
2. Then prefer a filename explicitly marked 双语精读.
3. Then prefer documents with a title, Chinese learning content, more learning-section markers, and more English source words.
4. Break any remaining tie by byte size and repository-relative path.

The stable ID format is `cambridge-XX-reading-test-X-passage-Y`. Repository paths always use forward slashes.
