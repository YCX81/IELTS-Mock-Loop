# Cambridge IELTS 12 Test 1 calibration

This directory stores the hand-calibrated source package for the first reading test in the local Cambridge IELTS 12 PDF (printed as Test 5).

Source scope:

- Passage and question pages: PDF physical pages 16-26
- Official Reading answer key: PDF physical page 117
- Repository test id: `cambridge-12-reading-test-1`

`calibration.json` is consumed by `work/integrate-c12-t1.mjs` after calibration is complete.
